# Генератор экзаменационных билетов — лабораторные 1 и 2

Единый проект для Windows, Python 3.10+: консольный режим первой лабораторной и графический режим второй. Файлы хранятся рядом с программой, независимо от текущей папки терминала.

## Быстрый запуск объединённого проекта

Графический режим (лабораторная №2):

```powershell
.\start.bat
```

Консольный режим (лабораторная №1):

```powershell
.\start_console.bat
```

Либо `start.bat --console`. Оба запуска используют Python с установленными зависимостями, включая локальное окружение Codex. Если подходящего Python нет, выполните `py -3 -m pip install -r requirements.txt`. Tkinter входит в обычную установку Python для Windows.

## Графический режим — лабораторная №2

1. В `students.xlsx` каждый лист — группа. Строка 1 — заголовки, с строки 2: A — фамилия, B — имя.
2. В `tickets.docx` каждый билет начинается абзацем `Билет N`, далее три нумерованных абзаца `1. Вопрос`, `2. Вопрос`, `3. Вопрос`. Поддерживается также нумерация средствами Word.
3. Запустите `start.bat`, выберите группу, затем студента. Кнопка генерации активируется только после обоих выборов.
4. После генерации открывается окно с номером и тремя вопросами. Запись к этому моменту уже сохранена в `results.xlsx`.
5. ESC закрывает окно билета и возвращает к выбору студента; главное окно продолжает работать.

Учебные примеры содержат две группы, пустую группу и пять билетов по основам Python. Их можно заменить собственными файлами. Кнопка «Создать учебные примеры» восстанавливает отсутствующие входные файлы, существующие не меняет. После редактирования источников закройте их в Excel/Word и нажмите «Обновить файлы».

Результат имеет столбцы: `Группа`, `Фамилия`, `Имя`, `Номер билета`, `Дата и время`, `Повтор (да/нет)`. Идентификатор студента — группа + фамилия + имя. При первом выборе случайно выбирается один из корректных билетов. При повторе используется номер из самой первой строки студента, а в конец добавляется новая строка с отметкой «да». История никогда не заменяется последним результатом.

Если некорректные билеты пропущены, выбор идёт из оставшихся номеров: например, 1 и 7. Перенумерация не выполняется. Билеты с менее чем тремя вопросами и нераспознанные заголовки логируются в `app.log`. Если вопросов больше трёх, используются первые три с предупреждением в логе. Если ранее назначенный билет удалён из Word, программа просит восстановить его, не меняя номер студенту.

Отсутствующий источник, неверный журнал или блокировка файла вызывают сообщение с кнопками повтора и отмены. При повторе сохранения билет и время не меняются. После отмены несохранённый билет не показывается. Пустая группа оставляет список студентов пустым, кнопку — неактивной. Кнопка «Открыть журнал» открывает `results.xlsx`; перед следующей генерацией закройте его в Excel.

## Файлы проекта

- `app.py` — общий запуск, `gui.py` — Tkinter-интерфейс.
- `ticket_core.py` — парсинг источников, назначение билетов, журнал результатов.
- `main.py` — консольный режим и общие функции сохранения Excel.
- `journal.xlsx` — записи первой лабораторной; `results.xlsx` — записи второй.
- `SPEC_EN.md` — подробное техническое задание на английском для этапа Prompt Engineering.
- `tests/` — автоматические проверки обеих лабораторных, включая UI и повторы.

Старый `journal.xlsx` сохраняется отдельно: в нём нет группы, поэтому его записи автоматически не переносятся в журнал второй лабораторной. Запускайте одну копию приложения одновременно.

## Консольный режим — лабораторная №1

## Запуск

1. Установите Python 3.10 или новее.
2. В терминале в папке проекта установите зависимость:

   ```powershell
   py -m pip install -r requirements.txt
   ```

3. Запустите `start_console.bat` двойным щелчком либо выполните:

   ```powershell
   py main.py
   ```

`start_console.bat` также поддерживает Python из локального окружения Codex, если обычный Python отсутствует. В текущем окружении нужные библиотеки уже доступны.

## Работа

- При запуске выводится «Для выхода нажмите ESC.» и путь к журналу.
- Введите фамилию в `Last name:`, нажмите Enter; затем имя в `First name:` и Enter.
- Пустой ввод и ввод только из пробелов отклоняются. Пробелы по краям удаляются.
- Приложение выводит случайный билет от 1 до 20 включительно. Номера могут повторяться.
- После каждого студента строка сразу сохраняется, затем начинается следующий ввод.
- ESC работает сразу, даже в середине ввода фамилии или имени. Backspace удаляет последний символ.
- Если Excel блокирует файл, закройте его и нажмите Enter: повторится сохранение того же студента с тем же билетом и временем, без дубля. ESC в этом ожидании завершит приложение; текущая несохранённая запись будет потеряна, ранее сохранённые останутся.

## Формат и сохранность

Первый лист содержит столбцы `Last name`, `First name`, `Номер билета`, `Дата и время`. При отсутствии файла он создаётся с шапкой. Дата и время записываются как дата Excel, по местному времени компьютера.

Существующий файл загружается перед каждой записью. Новая строка добавляется после последней занятой строки, ранее введённые данные не изменяются. Сначала полная книга сохраняется во временный файл в той же папке, сбрасывается на диск, затем заменяет журнал. При аварийном завершении во время сохранения предыдущая версия остаётся целой. После сообщения «Запись сохранена» новая строка уже находится в журнале. Абсолютная защита от аппаратной неисправности диска не гарантируется.

Если файл повреждён или его шапка изменена, приложение сообщает об этом и предлагает повтор после исправления; существующий файл не перезаписывается. Запускайте одну копию приложения за раз.

## Проверка по заданию

1. Введите трёх студентов, выйдите по ESC: в журнале шапка и три записи.
2. Запустите снова, введите двух: пять записей, первые три сохранены.
3. После сообщения «Запись сохранена» завершите процесс через диспетчер задач: последняя запись остаётся в файле.
4. Откройте журнал в Excel и введите студента: приложение покажет сообщение о доступе к файлу. Закройте Excel, нажмите Enter: запись сохранится один раз.
5. Нажмите Enter на пустой фамилии или имени: приложение повторит запрос.

Автоматические проверки:

```powershell
py -m unittest discover -s tests -v
```

Они используют временную папку и не меняют рабочий журнал.
